# Market Basket Analysis — Agent Guide

Before modifying this repository, follow these project rules:

1. **No local data storage** — the dataset is mounted by Kaggle; never commit or keep local
   copies of the data.
2. **Remote execution only** — analysis executes on Kaggle; nothing should run on a developer
   machine.
3. **Visibility gate** — ask the owner for visibility preferences before publishing the Kaggle
   kernel, any dataset, or this GitHub repository anywhere.
